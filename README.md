# Breathe ESG Platform

Enterprise ESG Data Ingestion & Review Platform.

Built using:

- Django REST Framework
- React.js
- Bootstrap
- Recharts

---

# Features

- CSV ESG ingestion
- Scope 1 / 2 / 3 classification
- Automated anomaly detection
- Review workflow
- Approval & rejection system
- ESG analytics dashboard

---

# Tech Stack

## Frontend
- React
- Axios
- Bootstrap
- Recharts

## Backend
- Django
- Django REST Framework
- SQLite

---

# Demo Data Sources

- SAP Fuel Data
- Utility Electricity Data
- Corporate Travel Data

---

# Local Setup

## Backend

```bash
pip install -r requirements.txt
python manage.py runserver
```

## Frontend

```bash
cd frontend
npm install
npm start
```
